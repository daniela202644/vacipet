# VaciPet

## Requisitos

- Node.js
- PostgreSQL

## Backend

Na pasta `backend-paste`, execute:

```powershell
npm install
npm start
```

O backend roda em `http://localhost:5000`.

## Frontend

Na pasta `frontend-paste/frontend`, execute:

```powershell
npm install
npm run dev
```

Abra `http://localhost:5173`.
